Прокрутка чата в дашборде
==========================

Page Up / Page Down листают историю чата — как в tmux


Что это
=======

Кнопка «🧠 Hermes» в веб-интерфейсе SSH-Connect открывает дашборд hermes,
а на его вкладке «Chat» — живой чат с агентом. История чата всегда листалась
колесом мыши. С 23.10.26 то же самое делают клавиши Page Up / Page Down —
как в tmux (см. «6. Move Cursor в SSH Connect.txt»).

Ничего настраивать не нужно: плагин уже установлен и включён на сервере.
Просто откройте дашборд и пользуйтесь.


Как пользоваться
================

1. Откройте дашборд (кнопка «🧠 Hermes») и перейдите в чат.

2. Кликните мышью в область чата — фокус должен быть внутри него.

3. Page Up / Page Down — история идёт по 12 строк за нажатие.

4. Shift + Page Up / Page Down — сразу на экран (аналог PgUp в tmux).

5. Колесо мыши работает как раньше.

6. Вне чата (меню, другие страницы дашборда) клавиши работают обычным
   образом — плагин не перехватывает их. Ctrl + PgUp/PgDn тоже не трогаем:
   это переключение вкладок браузера.

F12 (пауза Move Cursor) к чату отношения не имеет — Move Cursor работает
только с окнами KiTTY.


Если ничего не делает
=====================

1. Кликните в область чата — перехват срабатывает только при фокусе в нём.

2. Обновите вкладку дашборда (F5) — плагин подхватывается при загрузке
   страницы. Перезапускать сервер и программу не нужно.

3. Проверьте, что плагин виден. В консоли браузера (F12 → Console):

       window.__CHAT_SCROLL__

   Должно вернуться что-то вроде {version: "1.0.0", stepLines: 12, ...}.
   Пусто — плагин не загрузился, сделайте F5 ещё раз.

4. Проверьте, что плагин включён на сервере:

       hermes config get plugins.enabled

   В списке должен быть chat-scroll.


Настройка
=========

Шаг прокрутки (сколько строк за нажатие) задаётся константой STEP_LINES
в файле плагина на сервере:

    ~/.hermes/plugins/chat-scroll/dashboard/dist/index.js

По умолчанию STEP_LINES = 12. Изменили значение — сохраните файл и
обновите вкладку дашборда (F5). Больше ничего перезапускать не нужно.

Выключить плагин:

    hermes config get plugins.enabled
    hermes config set plugins.enabled '["homeassistant"]'

(список может отличаться — оставьте в нём всё, что было, кроме chat-scroll)

Включить обратно:

    hermes config set plugins.enabled '["homeassistant","chat-scroll"]'


Почему это не Move Cursor
=========================

Move Cursor живёт на уровне Windows: он перехватывает клавиши в системе и
шлёт в окно KiTTY события колеса мыши. Браузер он намеренно не трогает —
и не мог бы помочь: чат дашборда — это терминал xterm внутри веб-страницы,
и события колеса, отправленные «снаружи» программы, до него не доходят.
Проверено в обоих вариантах (PostMessage и SendInput): не работали, а
настоящее колесо мыши работало.

Поэтому прокрутка чата сделана внутри страницы — официальным плагином
дашборда, который вызывает тот же метод term.scrollLines(), каким сам
дашборд обрабатывает колесо мыши. Move Cursor при этом остался при своей
работе: листает историю tmux в окне KiTTY.


Как это устроено
================

- Плагин дашборда hermes (официальная система расширений): каталог
  ~/.hermes/plugins/chat-scroll/dashboard/ с manifest.json и dist/index.js.
  Сборка не нужна — файл обычный JavaScript.

- manifest.json объявляет плагин скрытым (без вкладки в меню дашборда),
  dist/index.js содержит саму логику.

- При загрузке страницы дашборд находит плагин, читает manifest и
  подключает dist/index.js. Плагин вешает обработчик Page Up / Page Down
  и, когда фокус в чате, зовёт term.scrollLines(±STEP_LINES).

- Включение — через plugins.enabled в config.yaml на сервере
  (пользовательские плагины hermes включаются явно, так задумано).

- Плагин лежит в ~/.hermes/plugins и переживает обновления hermes:
  после обновления достаточно обновить вкладку дашборда.

- Move Cursor к нему не относится: свой хук он ставит только для окон
  KiTTY/PuTTY, в браузер не заходит (подробности — в файле 6).


Полезно знать
=============

- Шаг прокрутки не зависит от параметра notches у Move Cursor — это две
  разные настройки (notches — для tmux в KiTTY, STEP_LINES — для чата).

- Колесо мыши и клавиши можно комбинировать: колесо — грубо, PgUp/PgDn —
  с шагом, Shift+PgUp/PgDn — сразу на экран.

- Если плагин когда-то удалят или выключат — верните его по инструкции
  из раздела «Если ничего не делает»: файлы можно восстановить из
  резервной копии или попросить у maintainers проекта.
