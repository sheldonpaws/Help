Чтобы сессия терминала не падала, установите tmux:
sudo apt update && sudo apt install tmux -y

Создайте защищенную сессию, нажав на кнопку "Новая". Назовите её. Имена могут быть любыми (буквы, цифры, дефисы, подчеркивания, без пробелов).
Появится второе окно kitty, свернётся, развернётся и перейдёт в режим tmux. Теперь всё, что вы здесь сделаете, **не умрет** при разрыве соединения.
И так далее.
Когда закончите работу в tmux, закройте терминал. Сохранение произойдет автоматически. 
Можете откключить соединение.
Чтобы восстановить сессию, выберите сессию и нажмите "Подключить".
Окно развернётся и перейдёт в режим tmux.
Чтобы подключить вторую сессию tmux, нужно сначала открыть второе окно kitty, воспользовавшись селектором справа.
И так далее.
Кнопка "Удалить" отправляет команду tmux kill-session -t имя_сессии

Кнопки "Удалить" и "Подключить" берут имя сессии из выпадающего меню.
Кнопка "Новая" выводит окошко для ввода имени сессии. 
Новые сессии tmux  открывают себе окна kitty автоматически. Кроме основного, которое всегда открывается при подключении к серверу.

tmux отрисовывает только текущее состояние терминала и не показывает историю:
чтобы это исправить, вставьте в файл ~/.tmux.conf
# Прокрутка колесом мыши (иначе история выше экрана недоступна)
set -g mouse on
# Большая история прокрутки
set -g history-limit 100000

Чтобы во время работы с агентом не появлялась ошибка Window too small в tmux:
вставьте эти строки в этот же файл
set -g window-size latest
set -g aggressive-resize on

Сессии hermes
посмотрерь сессии:
hermes sessions list --limit 12
флаг указывает на количество показываемых ссессий
Потом можно запустить агента и написать
"давай продолжим сессию" и id сессии
