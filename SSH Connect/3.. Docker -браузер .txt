Все манипуляции с докером рекомендую делать под root.
Docker и контейнер с браузером устанавливаются автоматически после первого нажатия на кнопку "Docker браузер"

В kitty отправляются команды:

sudo apt update
sudo apt install -y ca-certificates curl gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

И сразу же настройка docker-контейнера с  браузером:
 
 docker run -d \
 --name=chrome \
 -e PUID=1000 \
 -e PGID=1000 \
 -e TZ=Europe/Moscow \
 -e LC_ALL=ru_RU.UTF-8 \
 -p 3001:3001 \
 -v /opt/chrome/config:/config \
 --shm-size=1gb \
 --restart unless-stopped \
 lscr.io/linuxserver/chrome:latest
 
Когда появится приглашение к вводу новой команды, можете закрыть окно.

 Не закрывайте вкладку контейнера, оставляйте хотя бы одну. Если закроете все вкладки, то контейнер сломается. Если это все же произойдёт или интерфейс не откроется, то нужно войти под root, удалить контейнер и поставить его заново (скопировав в kitty строки 14-24).
 
 Проверить логи контейнера, если что-то пошло не так: docker logs chrome
Остановить контейнер: docker stop chrome
Запустить снова: docker start chrome
Удалить контейнер (данные в томе не удалятся вместе с нии): docker rm -f chrome

 Буфер обмена в докер- браузере работает с нюансом.
 Вы копируете информацию со своего компьютера, прежде чем вставлять её в целевое поле в докер- браузере, откройте боковую панель нажав на синюю полосочку у левого края, далее откройте соответствующий спойлер. Вставьте сначала туда. Так же и обратно.
 
 Когда закончите работу в докер-браузере, закройте вкладку вашего локального брауера.
