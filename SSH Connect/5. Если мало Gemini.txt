DeepSeek советует такой расклад.
Vision
(Анализ изображений)	Назначить	gemini-flash-lite-latest из набора Google AI Studio. mimo-v2.6-flash может не поддерживать зрение. Модели Gemini отлично подходят для анализа изображений.
Compression
(Сжатие контекста)	Назначить	deepseek-v4.1-flash	Задача требует скорости, а не глубокого мышления. deepseek-v4.1-flash имеет огромный лимит и очень низкую стоимость.
Approval
(Умное одобрение)	Назначить	deepseek-v4.1-flash Быстрая и дешевая модель для принятия решения об автоматическом одобрении низкорисковых команд. Использование дорогой модели здесь — расточительство.
Title generation
(Заголовки сессий)	Назначить	mimo-v2.6-flash Задача тривиальна. Можно оставить auto, чтобы не дублировать настройки, или явно указать mimo-v2.6-flash.
Review
(Фоновый анализ)	Назначить	kimi-k2.7-code или deepseek-v4.1-flash	Этот слот используется для фонового анализа и самоулучшения. kimi-k2.7-code хорошо подходит для анализа кода, deepseek-v4.1-flash — для общего анализа.
Memory query rewrite
(Переформулировка запросов)	Оставить auto	mimo-v2.6-flash (основная)	Задача не критична, и основная модель с ней справится.
TTS audio tags
(Теги для TTS)	Оставить auto	mimo-v2.6-flash (основная)	Требуется только при использовании Gemini TTS. Для базовой работы не нужно.
Voice chat
(Голосовой чат)	Оставить auto	mimo-v2.6-flash (основная)	mimo-v2.6-flash достаточно быстра для голосового режима.
Skills hub
(Поиск навыков)	Оставить auto	mimo-v2.6-flash (основная)	Как правило, не требует отдельной модели.
Triage specifier
(Детализация задач Kanban)	Назначить	deepseek-v4.1-flash	Дешевая и способная модель хорошо подходит для превращения однострочного описания в конкретную спецификацию.
Kanban decomposer
(Декомпозиция задач)	Назначить	qwen3.8-flash или glm-5.3-flash	Задача требует хорошего понимания логики. Эти модели обеспечат баланс между качеством и лимитами.
Profile describer
(Описание профиля)	Оставить auto	mimo-v2.6-flash (основная)	Короткий и дешевый вызов, основная модель справится.
Curator
(Анализ использования навыков)	Назначить	deepseek-v4.1-flash	Этот процесс может работать минутами, поэтому дешевая модель здесь очень выгодна.
Delegation
(Модель для субагентов)	Назначить	kimi-k2.7-code	Для делегирования задач, особенно связанных с кодом, лучше использовать специализированную модель. Это позволит субагентам работать эффективнее.
MCP
(Маршрутизация MCP)	Оставить auto	mimo-v2.6-flash (основная)	Обычно не требует отдельной модели.

Deepseek мне посоветовал установить на VPS 8 GB ОЗУ ещё файл подкачки на 8
Делать это нужно из под root, в kitty
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

Если это не сработает (у меня ввбило No such file or directory)
sudo dd if=/dev/zero of=/swapfile bs=1M count=8192 status=progress
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

И проверьте
swapon --show
free -h
Вы должны увидеть /swapfile в списке активных swap-пространств и общий объем swap 8 ГБ.

Верните на пользовательский профиль в прграмме.
Установите на сервер.
curl -fsSL https://lmstudio.ai/install.sh | bash
Запустите процесс.
lms daemon up
Найдите модель в каталоге
https://lmstudio.ai/models
На сервере
lms get название_модели
Запустите  API-сервер
lms server start --port 1234 --bind 127.0.0.1
Проверить
# 1. Проверить статус
lms status

# 2. Проверить, слушает ли сервер порт 1234
curl http://127.0.0.1:1234/v1/models
Если curl выдал список моделей (JSON) — значит, сервер работает (ине он выдал список загруженных моделей).

Далее зайти бы на http://127.0.0.1:1234 из Docker-браузера, но у меня ни в какую не получалось.
К счастью, Deepseek говорит, что, если агент установлен на той же машине, то можно вообще не открывать веб.
Достаточно просто вставить в ~/.hermes/.env
OPENAI_BASE_URL=http://127.0.0.1:1234/v1
OPENAI_API_KEY=lm-studio
Найти в hermes model Lm Studio, нажать ещё два раза Enter и выбрать модель. При заруске hermes опознает модель.
