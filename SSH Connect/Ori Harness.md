Запуск Hermes Agent через Ori Harness с Jev Router

## О чём этот документ

Этот документ описывает, как запустить ваш существующий Hermes Agent на OpenRouter с помощью Ori Harness — официального инструмента от OpenRouter, который избавляет от ручной настройки API-ключей и переменных окружения. Дополнительно описано, как задействовать Jev Router для автоматического выбора модели под каждую задачу.

Документ предназначен для пользователей, у которых Hermes Agent уже установлен и работает (например, на VPS), и которые хотят упростить управление доступом к моделям OpenRouter.


## 1. Что такое Ori Harness

Ori Harness — это часть семейства инструментов **Ori** от OpenRouter. Его задача — запускать уже существующий агент (Claude Code, Codex, OpenCode, Hermes и другие) на OpenRouter с минимальной настройкой.

Раньше для подключения агента к OpenRouter приходилось вручную прописывать множество переменных окружения и управлять API-ключами. Ori Harness делает это одной командой: вы запускаете агент через `ori`, и он стартует с уже подставленными credentials, моделями и настройками OpenRouter.

**Ключевое преимущество:** API-ключи больше не нужны. Ori использует OAuth PKCE через ваш аккаунт OpenRouter — вход выполняется через браузер, и никакие ключи не создаются и не вставляются вручную.

**Важно:** Ori Harness не заменяет ваш Hermes Agent и не переустанавливает его. Он использует тот экземпляр агента, который уже установлен на вашей машине (он ищет исполняемый файл в `PATH`). Если агент не установлен, Ori предложит его установить.


## 2. Требования

- Установленный Hermes Agent (на VPS, локальной машине или в контейнере).
- Аккаунт OpenRouter с положительным балансом (кредиты пополняются в личном кабинете OpenRouter).
- Терминал с доступом в интернет.
- Браузер для выполнения OAuth-входа (при работе через SSH на headless-сервере потребуется скопировать код авторизации вручную — см. раздел 5).


## 3. Установка Ori

Выполните одну команду в терминале:

```bash
curl -fsSL https://openrouter.ai/labs/ori/install.sh | bash
```

Эта команда работает на macOS, Linux и WSL. Для Windows PowerShell используйте:

```powershell
irm https://openrouter.ai/labs/ori/install.ps1 | iex
```

Установщик размещает исполняемый файл `ori` в локальной директории пользователя.

Чтобы обновить Ori в будущем, выполните:

```bash
ori update
```


## 4. Вход в OpenRouter (без API-ключей)

После установки выполните:

```bash
ori login
```

Откроется браузер, где вы войдёте в свой аккаунт OpenRouter и подтвердите доступ. Ori использует **OAuth PKCE** — стандартный протокол безопасной авторизации, при котором ваш пароль не передаётся приложению, а вместо API-ключа создаётся временный токен.

**Никакие API-ключи создавать, копировать или вставлять не нужно.** Ваши модели, кредиты и настройки организации автоматически подтягиваются из аккаунта OpenRouter.

Если вы уже экспортировали переменную `OPENROUTER_API_KEY` в окружении, Ori может её подхватить, но для базовой настройки это не требуется.


## 5. Запуск Hermes Agent через Ori

После входа запустите Hermes **не напрямую**, а через команду Ori:

```bash
ori hermes
```

Ori найдёт исполняемый файл Hermes в `PATH` и запустит его с уже подставленными credentials и настройками OpenRouter для текущей сессии. Всё, что вы укажете после `ori hermes`, будет передано агенту без изменений — ваши обычные флаги Hermes продолжат работать.

**Важно:** запускайте Hermes только через `ori hermes`. Если запустить Hermes напрямую, он не получит credentials OpenRouter от Ori.

### Работа на headless-сервере (SSH, контейнер)

Если ваш Hermes работает на удалённом сервере без графического браузера, при выполнении `ori login` callback на localhost может быть недоступен. В этом случае Ori покажет код авторизации прямо на экране — скопируйте его и вставьте в терминал при запросе. Код одноразовый и действует 10 минут.


## 6. Использование Jev Router для выбора моделей

По умолчанию Ori запускает Hermes с той моделью, которая указана в конфигурации агента. Чтобы задействовать **Jev Router** — интеллектуальный роутер, который анализирует каждый запрос и выбирает оптимальную модель по соотношению цена/качество — укажите его явно через флаг `--model`:

```bash
ori hermes --model typesafe/jev-router
```

Флаг `--model` задаёт модель для сессии, а Ori передаёт его в OpenRouter.

### Как работает Jev Router

Jev Router (`typesafe/jev-router`) — это не языковая модель, а **решатель**. Он оценивает тип задачи, её сложность и потенциальную пользу от более сильной модели, после чего выбирает модель из пула, которая соответствует этим критериям. Плагин для базового использования не требуется — достаточно указать модель `typesafe/jev-router`.

### Тонкая настройка через параметры плагина

Если вы хотите контролировать пул моделей для конкретного запроса, можно добавить объект `plugins` в тело API-запроса:

```json
{
  "model": "typesafe/jev-router",
  "plugins": [
    {
      "id": "jev-router",
      "cost_tier": "medium",
      "models": ["anthropic/*", "google/*"],
      "excluded_models": ["anthropic/claude-opus*"]
    }
  ],
  "messages": [
    {"role": "user", "content": "Суммаризируй этот отчёт."}
  ]
}
```

Параметры плагина:

- **`cost_tier`** — уровень стоимости: `"low"`, `"medium"` или `"high"`. Если не указан, используется политика Jev по умолчанию.
- **`models`** (или `allowed_models`) — список-включатель. Jev будет выбирать модель только из этого списка. Если список пуст или не указан, ограничение не применяется.
- **`excluded_models`** — список-исключатель. Имеет приоритет над `models` и никогда не игнорируется.

Списки поддерживают точные ID моделей (`openai/gpt-6-luna`), шаблоны (`anthropic/*`) и псевдонимы (`~openai/gpt-luna-latest`).

**Важно:** эти списки только **сужают** пул, из которого Jev выбирает. Они не добавляют новые модели, которых нет в исходном пуле роутера.


## 7. Полный воркфлоу

1. **Пополните баланс** в личном кабинете OpenRouter.
2. **Установите Ori:** `curl -fsSL https://openrouter.ai/labs/ori/install.sh | bash`
3. **Войдите в аккаунт:** `ori login` (откроется браузер, API-ключ не потребуется).
4. **Запустите Hermes с Jev Router:** `ori hermes --model typesafe/jev-router`

После этого все запросы Hermes будут идти через OpenRouter, а Jev Router будет выбирать модель под каждую задачу из доступного пула.


## 8. Частые вопросы

**Нужно ли переустанавливать Hermes?**
Нет. Ori использует уже установленный экземпляр агента, найденный в `PATH`.

**Нужен ли API-ключ OpenRouter?**
Нет. Аутентификация выполняется через OAuth PKCE при входе в браузере.

**Что будет, если запустить Hermes напрямую, без Ori?**
Hermes запустится, но не получит credentials OpenRouter от Ori. Для работы с OpenRouter через Ori всегда запускайте агент командой `ori hermes`.

**Можно ли использовать Jev Router без Ori?**
Да. Jev Router — это модель OpenRouter (`typesafe/jev-router`), которую можно указать в любом клиенте, поддерживающем OpenRouter. Ori просто упрощает настройку доступа.


## 9. Итог

Ori Harness — это инфраструктурный слой, который запускает ваш Hermes Agent на OpenRouter одной командой, без API-ключей и ручной настройки переменных окружения. Jev Router — это интеллектуальный роутер, который анализирует каждый запрос и выбирает оптимальную модель, экономя ваши средства. Совместное использование: `ori hermes --model typesafe/jev-router`.
