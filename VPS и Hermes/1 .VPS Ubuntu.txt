Не рекомендуется постоянно работать под root, поэтому нужно добавить другого пользователя:
adduser имя_пользователя
Задайте пароль (скопируйте его в Windows (Ctrl+C) и вставьте в терминал kitty (Shift+Insert). При этом ввода не будет видно. Это особенность семейства Linux. Они не показывают пароли учётных записей.
Дайте новому пользователю права sudo:
usermod -aG sudo имя_пользователя
В программе подключения замените поля пользователь и пароль на созданные,  нажмите сохранить и подключитесь.

Чтобы сессия терминала не падала, установите tmux:
sudo apt update && sudo apt install tmux -y

Создайте защищенную сессию. Назовите её. Имена могут быть любыми (буквы, цифры, дефисы, подчеркивания, без пробелов).
tmux new -s имя_сессии (кнопка "Новая")
После этой команды, вы перейдёте в терминал tmux. Теперь всё, что вы здесь введете, **не умрет** при разрыве соединения.
Когда закончите работу в tmux, нажмите кнопку "Отключиться",чтобы выйти. Сохранение произойдет автоматически. 
Можете откключить соединение.
Чтобы восстановить сессию, введите:
tmux attach -s имя_сессии (кнопка "Подключить")
Кнопка "Удалить" отправляет команду tmux kill-session -t имя_сессии

Кнопки "Удалить" и "Подключить" берут имя сессии из выпадающего меню.
Кнопка "Новая" выводит окошко для ввода имени сессии. 
Кнопка "Отключиться" отправляет команду tmux detach в существующую сесию, чтобы закрыть её.

tmux отрисовывает только текущее состояние терминала и не показывает историю:
чтобы это исправить, вставьте в файл ~/.tmux.conf
# Прокрутка колесом мыши (иначе история выше экрана недоступна)
set -g mouse on
# Большая история прокрутки
set -g history-limit 100000

Чтобы во время разговора с а агентом не появлялась ошибка Window too small в tmux:
вставьте эти строки
set -g window-size latest
set -g aggressive-resize on

В программе есть кнопка графического интерфейса сервера, при нажажатии на которую откроется файловый мнеджер, папки и файлы которого открываются двойным кликом.
Верхняя панель состоит из строки пути и кнопок управления ей, кнопка "Hermes", которая открывает его графический интерфейс, кнопка "Программы" со списком программ установленных на сервере, кнопки управления файлами и индикатор состояния.

Устанавите необходимые программы. Например:

Установка базового пакета:
sudo apt install python3 -y

Проверка установленной версии:
python3 --version

Для полноценной разработки на Python рекомендуется установить дополнительные компоненты:
sudo apt install python3-pip python3-dev python3-venv -y
Эта команда устанавливает:
python3-pip — менеджер пакетов Python, используемый для установки библиотек и зависимостей
python3-dev — заголовочные файлы и библиотеки, необходимые для компиляции расширений Python
python3-venv — модуль для создания виртуальных окружений
