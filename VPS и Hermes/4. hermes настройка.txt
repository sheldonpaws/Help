Экран 1.
На этом экране вам нужно выбрать Full setup.
И подождать отрытия экрана Select provider.

Экран 2 (Select provider)
На этом экране вам нужно выбрать провайдера (для начала отлично подойдет Google AI Studio).
После этого система попросит ввести ваш API-ключ и выбрать модели.
Нужно получить ключ, зайдя в Google AI Studio через Docker-браузер в программе (см. Docker -браузер).

После вставки ключа, сразу выйдет строчка Base URL, нажмите Enter и выберите модель 

Экран 3 (Select terminal backend)
На этом экране вам нужно выбрать, где именно агент будет запускать терминал для выполнения кода. Так как вы настраиваете всё на своей VPS, самым простым и производительным вариантом будет запуск прямо в этой системе.
Вам нужно выбрать Locl. Скрипт уже автоматически подсветил зелёным пункт (•) Keep current (local).
Что делать сейчас: Никуда не переключаясь, просто нажмите Enter на клавиатуре, чтобы подтвердить этот выбор.


Экран 4 (Select platform to configure)
На этом экране вам нужно выбрать ваши месседжеры.

Экран 5.
Рекомендуется отключить управление реальным компьютером и включить контекстный движок для лучшей памяти.
Что сделать сейчас (настройка списка):
Спуститесь стрелочками вниз к пункту Computer Use (macOS/Windows/Linux). Нажмите Пробел, чтобы снять галочку. На VPS без графического интерфейса эта функция не нужна и будет вызывать ошибки. image generaton и tex to spech тоже отключите

Поднимитесь к пункту Context Engine. Нажмите Пробел, чтобы поставить галочку [√]. Это поможет агенту лучше удерживать контекст ваших долгосрочных проектов.

Проверьте, чтобы пункт Code Execution оставался с галочкой [√] — это критически важно для проверки вашего кода.
A2A тоже поставьте.
Нажмите Enter, чтобы подтвердить весь список инструментов.

Экран 6 (Chose a provider)
На этом экране скрипт предлагает выбрать провайдера для работы с веб-браузером (это нужно, чтобы агент мог выходить в интернет, искать информацию, читать документацию и искать референсы).
Оптимальный выбор уже подсвечен зеленой стрелочкой — это Browser Use [free · local · cloud] - New SOTA web harness (CLI 3.0) [active]. Это современный и бесплатный инструмент, работающий локально.
Что делать сейчас: Ничего не меняя, просто нажмите Enter на клавиатуре), чтобы подтвердить этот выбор.

Экран 7 (Select search provider)
Выберите DuckDuckGo


Очерёдность и количество экранов может варьироваться в зависимости от ваших ответов.

   hermes setup          Re-run the full wizard
   hermes setup model    Change model/provider
   hermes setup terminal Change terminal backend
   hermes setup gateway  Configure messaging
   hermes setup tools    Configure tool providers

   hermes config         View current settings
   hermes config edit    Open config in your editor
   hermes config set <key> <value>
                          Set a specific value
