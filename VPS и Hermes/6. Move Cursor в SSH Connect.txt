Move Cursor в SSH Connect
=========================

Прокрутка истории tmux клавиатурой
==================================

По умолчанию tmux хранит историю каждой панели (до 2000 строк), но KiTTY не умеет её прокручивать — окно терминала одноразовое, сверх-истории нет. SSH-Connect решает это автоматически через встроенный хелпер Move Cursor конвертирует Page Up / Page Down в события колеса мыши, которые tmux понимает и листает свою историю.


Настройка на сервере (один раз)
==============================

SSH-Connect подключается и автоматически запускает Move Cursor на стороне клиента. Но сервер нужно настроить: добавьте в ~/.tmux.conf:

    set -g mouse on
    set -g history-limit 50000

Если tmux уже запущен, примените без настройки перезапуска:

    tmux source-file ~/.tmux.conf

history-limit действует только на НОВЫЕ панели.
Рекомендуется пересоздать старые сессии.


Использование
=============

1. Подключитесь к серверу через SSH-Connect (кнопка "Подключиться")

2. В окне KiTTY откройте или создайте tmux-сессию:
   tmux new -s work
   tmux attach

3. Нажимайте Page Up / Page Down — tmux покажет историю

4. Shift + Page Up / Page Down — горизонтальная прокрутка
   (если включена в конфиге move_cursor)

5. F12 — временная пауза перехвата


Хелпер стартует автоматически при открытии KiTTY и работает в фоне.
Чтобы остановить — завершите процесс pythonw.exe в диспетчере задач.
