Базовые команды для git commit и git push через командную строку.
1. Перейти в папку проекта
cd /путь/к/проекту
Если проект в разделе D на Windows, то сначала нужно написать D: и нажать Enter
2. Если репозиторий ещё не создан
git init
3. Привязать удалённый репозиторий, если ещё не привязан
Проверить привязку:
git remote -v
Привязать:
git remote add origin https://github.com/username/repo.git
4. git add . — добавляет все изменённые и новые файлы из текущей директории и её подпапок.
5. Сделать коммит
git commit -m "Описание изменений"
6.Отправить изменения на удалённый сервер
Первый раз:
git push -u origin main
Если у вас ветка master, то:
git push -u origin master
В дальнейшем достаточно:
git push
Если Git просит имя и email
Один раз на компьютере:
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"

Чтобы клонировать репозиторий, через командную строку войдите в папку, где хотите видеть этот репозиторий. На странице репозитория нажмите зелёную кнопку Code и скопируйте ссылку.
Вернитесь в командную строку и введите git clone скопированная_ссылка
